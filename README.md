
# BetterPV

[![Join the Discord](https://img.shields.io/discord/1487928162636533871?label=Join%20the%20Discord&logo=discord&color=5865F2&logoColor=white)](https://discord.gg/R5NdTVRDpb)

A better profile viewer for Hypixel SkyBlock.

Use `/pv <player>` to open a profile.

## Supported versions

- Minecraft 26.2
- Minecraft 26.3

## Features

- 15 profile tabs covering pretty much every part of SkyBlock
- Home overview with skills, slayers, SkyBlock level, networth, weight, coins and other stats
- Leaderboards powered by Elite, showing your rankings across SkyBlock
- Dungeon stats, floor times, classes, essence shops and XP calculators
- Full inventory viewer with backpacks, wardrobe, sacks, accessory bag, carnival masks and more
- Missing Accessories guide with upgrade paths, Magical Power gains and estimated costs
- Pets, auctions, collections and minions
- Garden, Mining, Foraging, Fishing and Crimson Isle progression
- Rift, Museum, Bestiary, Bingo and Chocolate Factory stats
- Profile switching with co-op member info
- Search for players, inventories and bestiary entries
- Senither + Lily weight
- Networth with multiple calculation modes
- Estimated item values on tooltips, with a clickable value breakdown
- Skill, Slayer and Dungeon XP calculators
- Custom item textures and SkyBlock item tooltips, including exotic armour colours and Seymour information
- Friends List shortcuts to open player profiles
- Party join shortcuts for profiles, Dungeons and Kuudra

## Commands

`/pv`

`/pv <player>`

`/pv <player> <page>`

Running `/pv` without a name opens your own profile.
